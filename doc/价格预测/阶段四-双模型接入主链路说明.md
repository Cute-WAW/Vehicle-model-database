# 阶段四：双模型接入主链路说明

> 记录日期：2026-04-15
> 对应阶段：`LightGBM模型改造实施清单.md` 阶段 4「接入预测主链路」

## 1. 本阶段目标

本阶段的目标是让现有预测主链路同时支持：

- `curve`
- `lightgbm`

并确保以下内容保持不变：

1. `/predict` 请求结构
2. `/predict` 顶层响应结构
3. 新车价推断逻辑
4. 相似车检索与调整逻辑
5. `C2B2C` 价格矩阵逻辑

## 2. 接入后的主链路

当前主链路仍然是：

`src/web_predictor_debug_step5.py`
-> `src/residual_predictor_step5.py`
-> `src/price_predictor_step5.py`
-> `src/price_logic_step6.py`

但其中“主模型预测”这一层已经从“只支持 curve”扩展为“支持 curve / lightgbm 双模型”。

## 3. 新增配置

新增配置文件：

- `config/model_strategy.yaml`

当前默认配置：

```yaml
default_model_family: curve
allow_curve_fallback: true
```

配置语义如下：

- `default_model_family`
  - 决定优先尝试的模型家族
  - 当前默认值为 `curve`
- `allow_curve_fallback`
  - 当 `default_model_family=lightgbm` 时，是否允许在失败后回退到旧 `curve`
  - 当前默认值为 `true`

## 4. 模型选择顺序

### 4.1 当默认模型为 `curve`

预测顺序为：

1. `curve` 品牌车系模型
2. `curve` 车型类别模型

其中品牌车系模型内部仍保持旧逻辑：

1. 分段品牌车系模型
2. 全量品牌车系模型

### 4.2 当默认模型为 `lightgbm`

预测顺序为：

1. `LightGBM` 品牌车系模型
2. `LightGBM` 车型类别模型
3. 如果失败且允许回退，则回退到：
   - `curve` 品牌车系模型
   - `curve` 车型类别模型

## 5. 保持不变的业务逻辑

本阶段没有改动以下逻辑：

1. `new_price` 自动推断
2. 相似车检索
3. `confidence_dynamic` 微调
4. 启发式修正（新能源 / 新车 / 高价车）
5. `C2B2C` 价格矩阵
6. 自适应区间扩展

因此，本阶段只是把“主模型预测价从哪里来”扩展成双模型可切换，并没有改变后续价格生成流程。

## 6. `debug` 字段更新

为区分 `curve` 与 `lightgbm`，本阶段扩展了 `debug` 字段。

### 6.1 保留的旧字段

- `model_used`
- `model_name`
- `model_type`
- `model_r2`
- `model_prediction`
- `similar_vehicles`
- `similar_avg_price`
- `adjustment_method`
- `adjustment_params`
- `adjustment_delta`

### 6.2 新增字段

- `model_family`
- `requested_model_family`
- `final_model_family`
- `fallback_triggered`
- `fallback_reason`

### 6.3 字段语义

- `model_used`
  - 继续表示命中层级：`brand_series` / `car_type`
- `model_type`
  - `curve` 场景下仍返回旧值，例如 `Power(segmented)`
  - `lightgbm` 场景下返回 `LightGBM`
- `model_family`
  - 当前命中的模型家族
- `requested_model_family`
  - 配置中优先尝试的模型家族
- `final_model_family`
  - 最终实际命中的模型家族
- `fallback_triggered`
  - 是否发生了 `lightgbm -> curve` 回退
- `fallback_reason`
  - 回退触发原因

## 7. API 兼容性说明

### 7.1 请求结构

`/predict` 请求结构保持不变，仍然使用：

- `vehicle_full_name`
- `brand_series`
- `years`
- `grade`
- `city`
- `mileage`
- `new_price`

### 7.2 响应结构

`/predict` 顶层响应结构保持不变，仍然返回：

- `predicted_price`
- `new_price`
- `residual_rate`
- `price_matrix`
- `identical_records`
- `debug`
- `error_message`

因此，现有调用方无需因为阶段 4 改造而调整接口字段。

## 8. 本阶段验证结果

本阶段已完成以下本地验证：

1. 默认配置下 `curve` 预测成功
2. 强制切换到 `lightgbm` 后预测成功
3. 人为制造 `lightgbm` 模型缺失后，成功回退到 `curve`

验证结论：

- 双模型切换链路已打通
- 回退机制生效
- `debug` 可以明确区分当前使用的是 `curve` 还是 `lightgbm`
