## 1. 本阶段新增/更新的测试入口

### 1.1 离线对比评估脚本

新增脚本：

- `experiment/compare_curve_vs_lightgbm.py`

用途：

- 在本地直接调用 `ResidualPredictor`
- 同口径对比 `curve` 与 `lightgbm`
- 输出总体指标、分桶统计和 Markdown 报告

### 1.2 单元测试与回归测试

当前测试文件：

- `tests/test_batch_modeling.py`
- `tests/test_lightgbm_model.py`
- `tests/test_dual_model_predictor.py`
- `tests/test_serialization.py`

覆盖范围：

1. 旧 `curve` 模型基础能力
2. `LightGBMResidualModel` 的预测、序列化和接口兼容性
3. 双模型切换
4. `lightgbm -> curve` 回退
5. 模型文件中运行时元数据完整性

### 1.3 细粒度质量验证脚本

新增脚本：

- `experiment/quality_validation_lightgbm.py`

用途：

- 检查 `LightGBM` 车龄单调性异常上涨比例
- 校验老车、新能源、里程分桶和典型品牌稳定性
- 输出专项质量报告与明细文件

## 2. 执行命令

### 2.1 离线对比评估

在项目根目录执行：

```powershell
$env:PYTHONIOENCODING='utf-8'
..\venv\Scripts\python.exe experiment\compare_curve_vs_lightgbm.py --sample-size 300
```

### 2.2 pytest 回归测试

在项目根目录执行：

```powershell

..\venv\Scripts\python.exe -m pytest tests\test_batch_modeling.py tests\test_lightgbm_model.py tests\test_dual_model_predictor.py tests\test_serialization.py -v
```

### 2.3 细粒度质量验证

在项目根目录执行：

```powershell

..\venv\Scripts\python.exe experiment\quality_validation_lightgbm.py --sample-size 300
```
