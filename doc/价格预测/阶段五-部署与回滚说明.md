## 2. 模型切换方式

模型切换通过配置文件完成：

- `config/model_strategy.yaml`

当前默认配置：

```yaml
default_model_family: lightgbm
allow_curve_fallback: true
```

### 2.1 保守模式

```yaml
default_model_family: curve
allow_curve_fallback: true
```

含义：

- 默认使用旧 `curve`
- 即使 `lightgbm` 已实现，也不切主

### 2.2 LightGBM 优先模式

```yaml
default_model_family: lightgbm
allow_curve_fallback: true
```

含义：

- 优先尝试 `lightgbm`
- 失败时自动回退到 `curve`

**当前已生效默认模式：**

- 当前项目默认模式就是本节配置，即 `lightgbm` 优先、`curve` 回退
- 本地环境与 Docker compose 重建后的 `web` 容器均已验证此默认模式生效

### 2.3 强制 LightGBM 模式

```yaml
default_model_family: lightgbm
allow_curve_fallback: false
```

含义：

- 只允许 `lightgbm`
- 不再自动回退
- 仅建议用于离线评估或明确灰度环境

## 3. 回滚方式

当发现 `LightGBM` 表现异常时，最快回滚方法是直接修改：

- `config/model_strategy.yaml`

回滚为：

```yaml
default_model_family: curve
allow_curve_fallback: true
```

这样即可把主链路恢复为旧 `curve` 行为，不需要删除 `lightgbm` 模型文件。
