# 车型库映射系统 - 文件架构

## 核心目录结构

```
车型库映射/
├── .spec/                          # Spec 文档
│   ├── requirements.md             # 需求文档
│   ├── spec_entity_extractor.md    # 实体识别器规格
│   ├── spec_vehicle_index.md       # 车型库索引规格
│   ├── spec_matching_engine.md     # 匹配引擎规格
│   ├── spec_testing.md             # 测试框架规格
│   └── spec_web_ui.md              # Web界面规格
│
├── config/                         # 配置文件
│   ├── entity_rules.yaml           # 实体识别规则
│   └── matching_config.yaml        # 匹配引擎配置
│
├── src/                            # 源代码
│   ├── web/                        # 匹配调试 Web 应用 (通用)
│   │   └── app.py
│   │
│   ├── entity_extractor.py         # 实体识别器 (通用)
│   ├── vehicle_index.py            # 车型库索引 (通用)
│   ├── matching_engine.py          # 匹配引擎 (通用)
│   │
│   │   # === C2B2C 价格模型 Pipeline (Step 1-5) ===
│   │
│   ├── batch_match_step1.py                # Step 1: 批量匹配 (数据预处理)
│   ├── extract_residual_data_step2.py      # Step 2: 提取残值数据
│   ├── residual_value_modeling_step3.py    # Step 3: 残值建模 (实验/探索)
│   │
│   ├── batch_model_trainer_step4.py        # Step 4: 批量模型训练器 (核心训练逻辑)
│   ├── build_brand_series_models_step4.py  # Step 4: 构建品牌车系模型脚本
│   ├── build_car_types_models_step4.py     # Step 4: 构建车型类别模型脚本
│   │
│   ├── price_predictor_step5.py            # Step 5: 价格预测器 (统一对外接口)
│   ├── residual_data_index_step5.py        # Step 5: 残值数据索引 (支持相似车查找)
│   ├── residual_predictor_step5.py         # Step 5: 残值预测核心逻辑 (策略/加权)
│   ├── tune_adjustment_params_step5.py     # Step 5: 参数自动调优工具
│   └── web_predictor_debug_step5.py        # Step 5: Web 调试界面 (FastAPI /random, /predict)
│
├── scripts/                        # 工具脚本
│   ├── build_index.py              # 构建通用车型索引
│   ├── run_benchmark.py            # 运行基准测试
│   └── c2b2c_price_model/          # C2B2C 价格模型相关脚本 (实验/验证)
│       ├── c2b2c_price_model_analysis.py       # 价格模型分析
│       ├── c2b2c_price_model_report.md         # 分析报告
│       ├── c2b2c_price_model_save_model.py     # 模型保存工具
│       └── c2b2c_price_model_test_predictor.py # 预测测试脚本
│
├── data/                           # 原始数据文件
├── doc/                            # 项目文档
├── index/                          # 索引文件 (pickle)
├── output/                         # 中间输出文件 (清洗后数据、CSV结果)
├── price_model/                    # 训练好的模型文件
│   └── c2b2c_model/                # C2B2C 专属模型
└── tests/                          # 测试数据与结果
```
