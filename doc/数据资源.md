# 数据资源说明

本文档详细说明 `data/` 目录下各个文件的作用、来源、格式及代码引用情况。

| 文件名 | 核心作用 | 引用代码 | 说明 |
| :--- | :--- | :--- | :--- |
| **力洋车型库精简5.csv** | **标准车型知识库** | `src/batch_match_step1.py` | 包含 Standard LevelID、年款、排量、指导价等核心信息。所有输入数据均需匹配到此库中的 ID。 |
| **youxinpai_vehicles.csv** | **优信拍原始数据** | `src/batch_match_step1.py` | 优信拍平台的历史车辆数据，作为"Step 1 批量匹配"的默认输入源。 |
| **有辆成交价格.csv** | **有辆原始数据** | `src/batch_match_step1.py` | 有辆平台的历史成交数据，包含`车型`列。程序会自动识别格式并进行匹配。 |
| **jzg_results_merged_success.csv** | **C2B2C 价格基准** | `scripts/c2b2c_price_model/...` | 精准 B2B/C2B/B2C 价格数据（合并自精真估API结果），用于构建 B端到C端的价差模型。 |
| **car_series.csv** | *(未使用)* | - | 冗余文件。程序实际使用的是 `config/dictionaries/car_series.csv`。建议保留作为数据备份。 |

## 详细文件格式

### 1. `力洋车型库精简5.csv`
*   **用途**: 提供车辆标准参数的"真理层"。
*   **关键列**: `level_id`, `brand_name`, `series_name`, `factory_price`(指导价), `displacement`(排量), `year`(年款).
*   **代码逻辑**: 在 `batch_match_step1.py` 中被加载到内存 (`liyang_dict`)，用于在匹配成功后检索车辆的完整信息。

### 2. `youxinpai_vehicles.csv`
*   **用途**: 批量匹配的输入数据源 A (优信拍)。
*   **引用**: `batch_match_step1.py` 的默认 `--input` 参数。
*   **特征**: 第一列通常为车辆长描述 (如 "奥迪A6L 2019款...")，程序会提取该列进行模糊匹配。

### 3. `有辆成交价格.csv`
*   **用途**: 批量匹配的输入数据源 B (有辆)。
*   **引用**: `batch_match_step1.py` 通过检测列名 `车型` 来识别此格式。
*   **特征**: 包含 `车型`, `成交时间`, `成交价格`, `里程` 等字段。Step 2 的提取脚本 (`extract_residual_data_step2.py`) 包含专门解析此文件行的逻辑 (`parse_youliang_line`)。

### 4. `jzg_results_merged_success.csv`
*   **用途**: 价格区间模型训练数据。
*   **引用**: `scripts/c2b2c_price_model/c2b2c_price_model_analysis.py`。
*   **内容**: 包含 `jzg_result` 列（JSON 格式），存储了同一车型在 B2B、C2B、B2C、C2C 等不同交易场景下的估值矩阵。
*   **价值**: 用于计算不同交易环节的价差比率，支撑 `ResidualPredictor` 输出完整的价格矩阵。

### 5. `car_series.csv`
*   **状态**: **冗余 / 备份**
*   **说明**: 实际生效的同名文件位于 `config/dictionaries/car_series.csv`。此副本目前没有被代码引用，删除不影响程序运行。
