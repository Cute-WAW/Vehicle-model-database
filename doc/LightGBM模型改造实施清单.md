# LightGBM 模型改造实施清单

## 文档说明

本文档用于跟踪二手车残值评估主模型从 `curve` 迁移到 `LightGBM` 的实施进度。

- 当前状态以复选框维护
- 每个阶段包含目标、任务、交付物、验收点
- 文档默认以“保留旧模型并存、逐步切换”为实施策略

## 项目目标

- 用 `LightGBM` 替换当前主残值模型预测能力
- 保持 `/predict` 请求和响应结构兼容
- 保留相似车修正逻辑
- 保留 `C2B2C` 价格矩阵生成逻辑
- 保留旧 `curve` 模型回退能力

## 成功标准

- 离线评估结果优于或不劣于当前 `curve` 模型
- 主接口字段保持兼容：`predicted_price`、`residual_rate`、`price_matrix`、`debug`
- 支持通过配置或代码开关切换 `curve` / `lightgbm`
- 关键测试、部署验证和回滚方案可用

## 阶段 1：冻结当前基线

### 目标

建立当前 `curve` 模型的结构认知、运行路径和性能基线，避免后续迁移时失去参照。

### 任务

- [x] 梳理当前主模型链路、模型目录、训练入口、预测入口
- [x] 记录当前 `curve` 模型基线指标
- [x] 统一确认训练输出目录与运行时读取目录
- [x] 补一份当前模型行为说明，明确优先级与回退逻辑

### 当前已确认事实

- 当前主模型为曲线拟合模型，候选函数包括 `Exponential`、`Polynomial`、`Power`
- 当前预测流程优先走品牌车系模型，失败后回退车型类别模型
- 当前运行时默认读取 `output/brand_series_models` 和 `output/car_types_models`
- 当前训练脚本默认输出目录与运行目录存在历史分叉，需要统一
- `C2B2C` 价格矩阵为独立辅助模型，不在本阶段替换范围内

- [x] 当前模型基线报告
- [x] 当前模型训练/加载目录约定说明

### 验收点
